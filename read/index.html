这套材料怎么读

  1. 先通读第 0 层词表。大部分词你早就认识，这一步是把它们正式“封存”为公理；中文速记只在这一层出现。
  2. 按顺序读各层：先看每节的正文规则，再看词条；开“自测模式”可以把释义藏起来，自己先想。
  3. 以后每完成一层：在 md 里写词条 → 运行 python tools/build_read.py 重新生成阅读版 → 运行 python tools/check.py --preview 验证用词不超纲。

三条硬规则

  • 从第 1 层起，每个新词只用“第 0 层 + 之前已定义词”的英语来解释。
  • 每个词条三句话：“apple” is a noun. / The meaning of “apple” is “…”. / Example: “…”。
  • 词形变化不算新词（went→go、books→book）；禁止 don't 这类缩合形式。

文件与工具

  • 数据源（唯一事实）：layers/layer0.md 到 layers/layerN.md（自动发现）
  • 阅读版生成：python tools/build_read.py
  • 严格检查：python tools/check.py --preview
